# c4d-scripts
Collection of Cinema 4D scripts that can be useful. 

Currently included:

**Camera Toggle**

Script that activates/deactivates the camera marked with a mograph selection tag. 
Sometimes you just want to be able to use a shortcut to toggle a specific camera, this script allows for that.

**Protection Toggle**

Toggle a protection tag on the selected objects.
If there's multiple objects selected and only a few of them have a protection tag they all get one. If all selected objects have a protection tag they all get removed.

**Remove Empty Materials**

Removes empty material tags from the selected objects or all the objects depending on the script. (there's 2)
